Admiralty accuracy (optional)

A saved tide location often sits some real distance from its nearest gauge above — Teignmouth, for example, is matched to Plymouth, over 50km away, and can genuinely run 35-40 minutes and the best part of a metre different at high tide. A free Admiralty Discovery API key lets each location learn its own real correction against Admiralty's own data for that exact spot, rather than relying on the nearest gauge unmodified. Get a free key at admiraltyapi.portal.azure-api.net (Products → UK Tidal API → Discovery tier).

Admiralty's API can't be called directly from a browser (their own docs confirm this — no CORS support on their side), so this also needs a small relay in between. See admiralty-proxy-worker.js in the project files — it deploys free on Cloudflare Workers in a few minutes and doesn't store or need to know anyone's key.
